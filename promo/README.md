# Промо-ролики Руф·КЛД

Готовые ролики лежат в `videos/` (1080×1920, 30 fps, своя музыка без авторских прав).

## Как сделать новый ролик
1. Сверстай анимацию как HTML-страницу 432×768 (пример — `tools/example_top5.html`): фон рисуется на canvas с масштабом 2.5, подписи — HTML-блоками, сцены по таймлайну через `performance.now()`.
2. Запусти локальный сервер в папке со страницей: `python3 -m http.server 8801`.
3. `python3 tools/make_video.py http://localhost:8801/страница.html <секунды> out.mp4`
   — скрипт замедляет время на странице, снимает кадры в полном разрешении и собирает плавное видео с музыкой из `tools/music.py`.

`record_site_demo.py` + `cut_site_demo.py` — запись живого сайта (первый промо-ролик) с подставными данными.

## Правила для роликов
- Фото пользователей — только одобренные модерацией, с ником автора.
- Без опасных трюков и «края»: упор на виды города. В конце — строка про безопасность.
- В конце — адрес сайта и «ссылка в профиле».
